## 第 34 轮：抓帧触发改判（帧号 → 墙钟 → guest tick）+ SFX 爆音修复

- **sokol 实测可跑**（之前只是没人验）：`-Render sokol` → `host: render backend = sokol`、
  `sokol: backend=D3D11`、20 s **3207 帧 / 159 fps**（GDI 是 637 帧 / 31.9 fps）。
  `swap_interval=1` 在无显示/RDP 会话里不生效。exe 95,744 B vs 287,232 B。
- **验收标准改判**：`docs/BACKEND.md` §13.6 第 2 步原写"GDI vs sokol **同帧**截图逐像素一致"——
  这标准本身错的，帧号只在同帧率下才是"时刻"。新增 `--shot-time=<ms>`（墙钟）后仍有
  ±1 帧周期的采样误差（GDI ±31 ms 实测迟到 16 ms ⇒ 比 sokol 多走一步动画 ⇒ 逐像素差 10.29%，
  用户肉眼判定"差 1 帧"）。最终加 **`--shot-tick=<n>`**（按游戏 BIOS tick `0x40:0x6C`，
  `dos.c bios_tick_thread` 18.2 Hz 独立推进，与帧率无关）= 同一 guest 状态。
  新增 `host_age_ms()` / `host_guest_tick()`（`host.c` + `host.h`）。
- **SFX 爆音已修**（`src/ail.c`）：原路径一次音效 = 一次 `waveOutClose`+`waveOutOpen`
  （`AIL_stop_sample` 关、`AIL_init_sample` 又关、`sample_play` 再开）。改为 `sample_stop()`
  常驻设备（`waveOutReset` + 等 `WHDR_DONE` + `UnprepareHeader`）+ `pcm_apply_ramp()`
  首尾 3 ms 斜坡。实测 SFX = 667 B @11025 Hz = **60 ms**、1.7 次/秒 ⇒ `(cut)` **0 次**，
  **主因是起停阶跃不是硬切**。残余（音乐 `Sleep(200)` 循环重提交、重触发硬切）留给软件混音。
- **坑**：`--screenshot` **必须绝对路径**——宿主 chdir 到游戏目录，相对路径只在日志留一行
  `host: cannot write frame dump …`。已写进 ENVIRONMENT.md / DEBUG-MANUAL.md / AGENTS.md。
- `aux_build.bat` 改为透传 `%*`（原来只透传 target，加不了 `-Render`）。
